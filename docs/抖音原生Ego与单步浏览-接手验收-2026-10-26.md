- `SocialAccounts.browse`、owner HTTP 路由、模型工具、原生账号面板与独立预览新增手动 open/current/next/stop/history。
- 只允许抖音固定推荐页；不接收任意网址、自动循环、次数参数或自主权限。每次提取只返回当前可见作者、文案和播放元数据；结果明确 visualUnderstanding=false、autonomous=false。
- next 必须匹配最近观察的媒体源指纹；动作前消费旧观察，未知执行不会用同一观察再次点击。指纹只用于防旧页面重放，**不是稳定业务视频 ID**，也不能用于评论/回复/投稿绑定。
- 当前页播放事件和动态媒体受暂停约束，每次观察后暂停；这是页面播放器保护，不能替代浏览器全局静音验收。

- stop 可取消在途读取，等待旧请求清理后停止自己的执行器；历史只读、按账号隔离、最多20条且 UTF8 JSON 不超过24KB。停止回执不返回旧账号历史。
