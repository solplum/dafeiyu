## 可接入接口

```js
import {
  DouyinBrowser, createDouyinToolRunner, registerDouyinBrowserTools,
} from './douyin-browser.js';

const browser = new DouyinBrowser({
  enabled: true,
  runScript: createDouyinToolRunner({ ctx, controlAccess }),
});
const stopTools = registerDouyinBrowserTools(ctx, {
  browser, getExecutionContext, controlAccess,
});
```

只读模型工具为 `dafeiyu_douyin_browse`：

```js
{ operation: 'search', keyword: '公开关键词' }
{ operation: 'watch', url: 'https://www.douyin.com/video/1234567890123456789', frames: 1 }
```

关键词最多100字符；URL仅接收 `https://www.douyin.com/video/纯数字`，不接受任意域、登录/创作者页、查询参数、片段、用户名或密码；帧数只能1–3。模型没有脚本、选择器、文件路径、点赞、评论、关注、私信、下载或发布参数。

`browser.probe(options)` 是固定 `DeepSeek Harness` 公开搜索，模型路径须真实主人 Agent、当前 browser scope 和授权回查。面板的“检查抖音浏览”由已有 `resolveCapabilityContext → controlAccess.runProbe(current, 'browser', operation)` 创建受管验证 Agent，并在每次动作前后重验本次 HTTP 主人权限与运行实例；不会将该 Agent 伪装为主人或开启模型循环。普通 HTTP 请求不能自行指定 Agent、脚本或取得验证 grant。`browser.browse(input, {agent,parent,signal,authorize})` 可供代码内部调用；`parent` 传真实外层 ToolRunContext，不制造 PTC 父令牌。

`browser.status` 为被动快照，不启动浏览器或请求网站：

```js
{
  configured, enabled, active, cleanupPending,
  readiness, // not-verified / needs-login / verification-required /
             // read-verified / cleanup-unconfirmed
  lastCheck: { ok, at } | null,
  lastResult: { ok, state, at, frameCount, note } | null,
}
```

成功读取记录10分钟后失效。`needs-login` 和 `verification-required` 是平台限制，不得显示为浏览检查通过。搜索标题只证明读过检索结果；只有视频实际时间、readyState 和有限截图能证明采样，均不表示完整看完或理解整段视频。截图若能生成，通过宿主附件服务返回，模型结果不携带任意本机路径。

## 权限与清理

现有 controlAccess 会拒绝所有普通 `ego_script`。新增的 `executeTrustedBrowserRead` 是未注册为工具的内部方法，仅供固定代码 builder 使用：

- 模型路径需要真实已注册主人 Agent、当前回合、相同运行实例和 browser scope；面板路径只接受已有 runProbe 创建、同实例且主人 HTTP authorize 持续有效的 probe scope。child 与自主活动 scope 不能使用此入口，模型也不能创建 probe。
- 生成一次性 callId，并绑定 Agent、scope state、精确参数 SHA-256 和自有 `dfy-douyin-UUID` 空间。
- 唯一匹配的嵌套 `ego_script` 仍经 `canonicalToolCall → ToolRuntime.execute → guard/around`；改脚本、加参数、换 Agent 或重放均拒绝。
- 不放开一般脚本/CLI/CDP/HTTP 工具，也不新增模型可见的授权入口。内部方法不是脚本安全解释器；调用方只能是这里经过审查的固定 builder，不能把用户脚本、网页文本或模型参数作为 script 传入。
- 沿用共享浏览器占用、取消及实际工具完成边界。取消信号不等于已清理。失败后只能在旧调用完成后执行固定的“关闭本次自有空间”清理；清理脚本由 controlAccess 自己生成，不接受用户代码。
- 未确认清理保留占用，禁止启动下一次读取。卸载会取消并等待当前读取，应在撤销对应主人 Agent 前调用 `await browser.dispose()`。

正常脚本在 finally 关闭自有空间，并移除临时截图目录，不关闭或清理用户其他空间、浏览器 profile、Cookie 或缓存。
