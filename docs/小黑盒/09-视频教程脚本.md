# 视频教程拍摄脚本（安装之后 · 全流程）

> 配套文件：`tools\安装.bat`、`tools\启动.bat`
> 用途：给你拍视频用。每一集都有【时长 / 前置 / 屏幕上做什么 / 口播 / 常见坑】五栏，照着录就行。
> 全片建议拆 4 集主线 + 3 集番外，主线合计 15 分钟左右。


## 拍摄前的准备（一次性，不录）

- 录屏：OBS（推荐）或 Win+G。1080p 60fps 够了，麦克风单独试一次。
- 屏幕：分辨率 1920×1080，缩放 100%；记事本字号调到 18，终端字号调到 18（观众手机上看不清小字）。
- 演示机状态：Node、DSH、SnowLuma 都装好并登录好（视频里不装，只演示"装的过程"）。
- 关掉：微信/QQ 弹窗通知、桌面上的私密文件、浏览器书签栏里带 token 的东西。
- 用一个干净目录演示，但录制时直接回车用默认路径，观众照做最不容易出错。
- 录之前先自己跑一遍 `安装.bat`，把下载和 npm 缓存预热好，正式录的时候才快。


## 第一集 · 她是什么（1.5 分钟）

**前置**：不需要打开任何软件。用成品素材 + 结构图。

**屏幕上做什么**
1. 前 10 秒直接放她主动发消息的聊天记录（最抓人的一句放最前）。
2. 画/贴一张结构图：QQ 客户端 ← SnowLuma（网关）← qq-bridge（桥接）← DeepSeek Harness（大脑）。
3. 最后 10 秒放一张她写日记/发图的截图，留钩子。

**口播**
> 这不是什么 AI 女友 app，是我自己搭的一只。
> 她跑在我自己的电脑上，接在我自己的 QQ 里。
> 这条链路四层：QQ、网关、桥接、大脑。下一集开始，从装 Node 开始一步步来。

**常见坑**：别一上来就讲技术栈，先给情绪。


## 第二集 · 准备工作（3 到 4 分钟）

**前置**：全新环境。

**屏幕上做什么**
1. 浏览器搜 Node.js 官网，指出左边那个 LTS 按钮，下载、双击、一路下一步。
2. 装完重启电脑（一定要强调这句）。
3. 打开 cmd，输入 `node -v`，展示版本号。
4. 装 DeepSeek Harness，装完打开一次。
5. 装 SnowLuma，双击它的 launcher，用手机 QQ 扫码登录一个号（建议小号）。
6. 打开 SnowLuma 的界面，指出"访问令牌"那串字在哪，先复制到记事本备用。

**口播**
> 三个东西：Node 是她跑起来的引擎，Harness 是她的脑子，SnowLuma 是她连 QQ 的嘴巴。
> 令牌那串一定要先存好，第三步要填。

**常见坑**：Node 装完不重启，`node -v` 会提示找不到命令，这段一定要留在视频里。


## 第三集 · 一键安装（4 到 5 分钟，重头戏）

**前置**：第二集的三样都装好。

**屏幕上做什么**
1. 双击 `安装.bat`，展示欢迎界面。
2. 问"装到哪个文件夹"，直接回车（默认路径），口播说明可以自定义。
3. 第一步检查 Node，展示 `OK Node.js vXX`。
4. 第二步下载，进度条走的时候别剪，切个近景讲两句。
5. 第三步 npm install，展示"这一步最慢，三五分钟"，强调不要关窗口。
6. 第四步生成配置文件。
7. 第五步弹出记事本，逐条填三个值：`ownerQQ` / `allow.private` 里两个 QQ 号 / `snowluma.accessToken`。
8. Ctrl+S 保存，关掉记事本，回窗口按任意键。
9. 展示"装好了"那一屏。

**口播（填配置那段，建议原词念）**
> 这里三个地方要改。
> 第一个 ownerQQ，填你自己的 QQ 号。
> 第二个 allow.private，里面有两条，一条是你的号，另一条换成她的号，就是你要给她的那个 QQ。
> 第三个是 SnowLuma 的访问令牌，就是刚才复制的那串，粘进来。
> 改完 Ctrl+S，关掉记事本。

**常见坑（都要保留在成片里）**
- npm 报错：脚本会问"要不要换国内镜像重试"，按 Y，通常就好了。
- 下载失败：视频里展示手动打开 `gh-proxy.com/https://github.com/Derpyu520/qq-bridge`，Code、Download ZIP，解压到刚才那个目录，再跑一次脚本（它会自动跳过下载）。
- 目录已存在但不是完整仓库：提示换个目录或先删掉，讲清楚这是保护机制。


## 第四集 · 启动 + 第一次对话（3 到 4 分钟）

**前置**：第三集装完，SnowLuma 在跑、DSH 已打开。

**屏幕上做什么**
1. 双击 `启动.bat`。
2. 展示自动检查两个端口：3000（SnowLuma）和 43129（Harness），两个都 OK。
3. 窗口开始刷字，口播"这是正常的"。
4. 强调：这个窗口不能关，最小化就行。
5. 切到 QQ，给她的号发第一句：「在吗」。
6. 等回复（第一次慢是正常的），展示她的回话。
7. 结尾演示下线方式：关掉那个窗口。

**口播**
> 她现在跑起来了。窗口别关，关了就等于她下线。
> 去 QQ 找她，第一句随便说。第一次回得慢，因为模型要热身，之后就是秒回。

**常见坑**
- 卡的画面：如果 3000 没通，脚本会直接提示"SnowLuma 没在跑，去双击 launcher 扫码"，这段一定要录进去。
- DSH 没开时脚本只给提示不阻断，说明"她可能不理你，八成是这个原因"。


## 番外一 · 她会记住你（3 分钟）

- 讲人账：她记你的作息、口味、话题，存在本地一个文件里。
- 演示：晚上跟她说一句"我最近总熬夜"，第二天她主动提醒你。
- 讲边界：她的记忆是文件，你能看、能改、能删，数据全在你机器上。


## 番外二 · 常见故障排查（2 分钟）

一张表，逐个演示：

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 她完全不回 | SnowLuma 掉线 | 去 SnowLuma 窗口看还在不在线，掉线就重新扫码 |
| 她回得很慢或卡住 | 会话卡在上一轮 | 重启桥接；或在控制台把她的会话重置 |
| 她只在你 @ 她时说话 | 群聊默认只认 @ 和你的发言（有意设计） | 私聊不受影响；群里要她说话就 @ 她 |
| 启动脚本一闪就没了 | 缺 config.json | 先跑 `安装.bat` |
| npm 装不上 | 网络 | 换国内镜像重装 |


## 番外三 · 进阶（每条 1 到 2 分钟，可做合集）

1. 给她声音：本地语音合成，参数是调出来的，直接给一套现成的。
2. 给她图库：她收到/发出的图自己存，可以翻。
3. 给她日记：她自己写，你不看也行。
4. 给她画笔：接本机出图（这次刚给这套打通的那部分），她能按你一句话画一张再发给你。
5. 群聊策略：@ 才理她，避免她打扰别人。


## 发布建议

- 封面：用她的聊天记录截图 + 一句话（比如"她昨晚说有点想你了"）。
- 前 15 秒必须有"她主动发消息"的画面，不要从安装讲起。
- 分 P：主线四集 + 番外合集一个，主线每集 3 到 5 分钟最好。
- 标签：AI、QQ机器人、本地部署、自建、Node.js。
- 隐私：任何 token、QQ 号、路径里的用户名，录之前全部遮掉；也提醒观众别把自己的发出来。
- 结尾统一一句话：完整脚本和安装器都在仓库里，说明文档第几集对应第几个文件夹。
