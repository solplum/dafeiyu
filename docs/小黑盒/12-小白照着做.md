# 小白版 · 照着做就行

> 这份是给**完全不懂的人**看的。每一步只做一件事，做完会有"你应该看到什么"。
> 看不懂的词我已经尽量不用了；万一出现，后面都跟着解释。
> 配合视频用：视频按这份的顺序录，观众按这份的顺序做，能对上。


## 你要准备的东西（四样）

1. 一台 Windows 电脑（能一直开着最好）
2. **一个 QQ 小号**（专门给她用，别拿你自己的主号）
3. 一个 DeepSeek 的账号（要充几块钱，用来给她"脑子"）
4. 半小时左右的时间（一半时间在等下载）

先记住一句话，后面所有事都围着它转：

> **小号是她的身体，电脑里的程序是她的脑子和嘴。**


## 第一步：装三个东西（约 15 分钟）

三个都要装，装完重启一次电脑。**每一个都是双击、下一步、下一步。**

| 装什么 | 从哪来 | 装完怎么确认 |
|---|---|---|
| QQ 桌面版 | 搜"QQ 官网" | 能打开、能登你的小号 |
| Node.js | 搜"Node.js 官网"，下 LTS 那个 | 不用管，装完重启就行 |
| SnowLuma | 搜 GitHub 上的 SnowLuma，下 Windows 版，解压到 `E:\SnowLuma` | 见第二步 |

> 路径一定要**纯英文**：`E:\SnowLuma` 可以，`E:\我的软件\鲸鱼` 不行。
> 装了"加速器/游戏加速"之类的先关掉，它会挡住下载。


## 第二步：让她能连上 QQ（约 5 分钟）

1. 进 `E:\SnowLuma`，双击里面的 `launcher.bat`
2. 会开一个窗口刷字，**别关它**
3. 浏览器开 `127.0.0.1:5099`，会出现一个二维码
4. 用**小号的手机 QQ** 扫码登录
5. 登录后，在这个网页里把两个开关打开：

```
HTTP 服务   端口填 3000
WS 服务     端口填 3001
```

6. **然后找那串令牌。这里第一次用的人 100% 会卡住** —— 因为**刚装上时它还没有令牌**，令牌是你"创建这条服务"的时候才生成的：

```
左边菜单 → 配置
  └ 「HTTP API」这一块，如果是空的，会有一个按钮：创建第一个   ← 先点它
      └ 弹出来的窗口里：
           名称    http-1（默认就行）
           主机    127.0.0.1
           端口    3000
           路径    /
           消息格式  选"数组"
      └ 往下找到「鉴权」分组
           └ 输入框写着「授权 Token」→ 点右边的按钮生成一串
      └ 点「创建节点」保存
  └ 回到列表，那条东西里现在就有 Token 了 → 点进去复制它，存到记事本
```

　　（「WS 服务端」那一块如果也是空的，同样点"创建第一个"，端口填 3001、它自己生成的 Token 不用抄 —— 那是另一串，程序会自己读。）

　　⚠️ 主机那栏必须是 `127.0.0.1`。写成别的地址，保存时会报"未绑定本机地址时必须填写令牌"。
　　⚠️ 令牌要够长（至少 16 位），所以**别手打，用右边那个生成按钮**。

**你应该看到**：网页上出现小号的头像和昵称，状态是"在线"。
**卡住了**：二维码刷不出来 → 把 QQ 桌面版完全退掉（右下角托盘右键退出），再点一次 `launcher.bat`。


## 第三步：装"桥接"（约 10 分钟）

1. 打开我给你的那个文件夹，双击 `安装.bat`
2. 它问你"装到哪个文件夹" → **直接回车**
3. 它会自己下载、自己装，中间会刷很多字，**别关窗口**（最慢的一步，三五分钟）
4. 装完会自动弹出一个记事本，让你填三个地方：

| 填什么 | 填成什么 |
|---|---|
| `ownerQQ` | 改成**你自己的** QQ 号 |
| `allow.private` 里那两个数字 | 一个是你自己的号，另一个改成**小号的**号 |
| `snowluma.accessToken` | 粘第二步复制的那串令牌 |

5. 改完按 `Ctrl+S` 保存，关掉记事本，回到那个窗口按任意键

**你应该看到**：窗口最后显示"装好了"。
**卡住了**：装依赖那步报错 → 它自己会问"要不要换成国内镜像重试"，按 Y。


## 第四步：开起来，跟她说第一句话（约 3 分钟）

1. 双击 `启动.bat`
2. 窗口会先检查两个东西，然后开始刷字，**这个窗口一直开着别关**（最小化就行）
3. 拿你自己的手机 QQ，给**小号**发一句：`在吗`

**你应该看到**：她回你话了。第一次可能要等十几秒，之后就是几秒。

> 这个窗口关了 = 她下线。想让别人找不到她就关掉，想让她活着就留着。


## 第五步：让她像个人（这一步才是关键）

前面四步只是"能跑"，让她**像个人**靠的是那份"角色卡"（一个文本文件）。
里面写什么，她就变成什么。三个立刻见效的写法：

- **写她的话有多短**：默认一句话 1~15 个字，别让她写小作文
- **写她会顶嘴**：允许她说"不"、允许她吐槽你熬夜
- **写五个对话示例**：比如

```
你：在吗
她：在

你：帮我查天气
她：自己看手机去
她：（还是查了）……明天小雨，带伞

你：你真聪明
她：这有什么
```

**示例比形容词管用一百倍。** 你写"她温柔善良"没用，你写"被夸了会嘴硬说这有什么"，她就活了。


## 出问题了先看这三条

| 现象 | 九成是这个 | 怎么办 |
|---|---|---|
| 她一句都不回 | 第二步那个窗口关了 / 第三步的窗口关了 | 两个窗口都开回来 |
| 她回得很慢，或者卡住不回 | 上一轮还没跑完 | 关掉第三步的窗口，重新双击 `启动.bat` |
| 群里她不说话 | 群里默认只理被 @ 的 | 私聊不受影响；群里要她说话就 @ 她 |

还不行就把**第三步那个窗口最后 20 行**截图发我，别的都不用管。


## 想知道原理的话（不看也行）

```
你的手机 QQ ──→ 腾讯服务器 ──→ 电脑上的 QQ（小号）
                                   ↑
                          SnowLuma（第二步装的，负责"翻译"）
                                   ↑
                          桥接（第三步装的，负责"像个人"：什么时候回、
                          分几条、隔多久、记得住昨天）
                                   ↑
                          DSH（她真正的脑子，负责"想说什么"）
```

所以四句话：
1. QQ 是她的**身体**
2. SnowLuma 负责**听得见、说得出去**
3. 桥接负责**像人**（节奏、分条、记忆）
4. DSH 负责**想内容**（角色卡就是给它看的）
