## 额度与实际用量

Token 与娱乐时间分别记账，Token 不是人民币，也没有据此生成金额账单。每日 **50,000 Token 免扣**、每月 **200,000 零花 Token** 是本轮选定、可调整的产品默认，不能解释成用户授权了某项人民币支出。每日免扣不结转，每月零花可累积。

用户交办的对话、工作及其子任务归 `user-task`，只记录用量，不扣她的免扣额或零花 Token。自主任务归 `autonomy`，先用每日免扣，再扣零花；失败或取消时，已经报告的真实消耗照常结算。点击、等待和没有调用模型的工具动作不按次数编造 Token。

按宿主报告的 usage 记账：有有效总数时采用总数；无总数时才合计规范化的输入、输出及缓存桶。推理量属于输出，不重复叠加；缓存也不再加进已经包含它的总数。缺失、矛盾或无法确认的 usage 保持未计量，不写成 0。

每次自主请求预留 **16,384 Token**，自主模型输出上限为 **4,096 Token**。两者都不是输入、缓存、推理与输出合计的绝对硬限；超出可用额度仍按真实消耗记债，负余额和超支明确显示，并阻止新的自主调用。未知自主请求保留预留及去重证明；只能在主人明确确认已停止并接受“仍未计量”后释放预留，不伪造消费、退款或重放模型。

月额在授权的写事务中按月同步一次，重载不重复发放。GET 只显示实际余额和交易；`pendingMonthlyTokens` / `projectedAvailableTokens` 是尚未落账的预计额度，普通界面仅提示“本月待入账”，不把预计值加进实际余额或生成交易。

## 实现与权限边界

- 归属由受验证的账号、身份及宿主会话绑定确定。身份切换用稳定 alias 保留旧 scope，已经落账的请求不改归属；模型参数、角色声明和提示词不能指定付费方。
- 子任务只继承真实宿主的父子注册表与会话 lineage，派发前固定归属；不把普通工具结果通知当成新的模型调用。legacy 路径另行规范化其实际 OpenAI/DeepSeek usage；外部执行器未提供权威用量时保持未知，不按运行时长估算。
- 全局余额与额度仅主人可见。主人只读模型工具返回共享额度和本人请求元信息；附加账号不注册该工具，scope 视图不暴露全局余额、策略或他人记录。自主模型只收到本账号摘要，不获得主人全局账本。
- `tokens/status` 为 GET；`tokens/config`、`tokens/bonus`、`tokens/acknowledge` 为 POST。真实 owner 校验、运行实例复核、空闲门禁、CAS 与 API 往返已验收。发放使用 UUID 幂等；未知结果不自动重发。用户明确点击“确认同一笔发放”时先读账本，已到账则只读确认，否则仅以原 UUID、原金额和新读取的版本完成原申请。
- `TokenPanel` 嵌在生活页，独立草稿并汇入主页面未保存状态，不依赖旧 life 响应携带 Token 数据。设置、预留、发放和明细在高级设置；刷新保留其他生活草稿。仅用量或入账导致版本变化、策略与基线完全相同时可采纳新 CAS；真正策略变化仍须明确处理冲突。

主要实现位于 `account-identities.js`、`token-budget*.js`、`token-usage-bridge.js`、`token-accounting.js`、`token-subagents.js`、`legacy-token-meter.js`、`token-panel.js` 与 `client.js`。真实证明保存在本任务私有 `work/token-integration-20261025/`；不将原始 trace、账号资料、完整会话标识或私人截图纳入源码包。

### 修复及离线验证

1. **外部任务防重**：计量包装层原先每次生成随机 requestId，同一任务在首调用未结束或中断重载后可能再次进入外部执行器。现按全量持久任务绑定和稳定请求 ID 拒绝重复派发，兼容旧随机请求记录、尚未退役的会话及更换执行器；确认未知用量不构成重执行授权。已取消的输入在绑定和执行前拒绝。绑定已落盘而执行尚未确认时也保持阻止，不以可用性为由重试。
