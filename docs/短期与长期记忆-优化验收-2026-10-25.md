# 短期与长期记忆：优化及验收

开发与回归日期：2026-10-25；实际桌面续验：2026-10-26 北京时间 09:52–10:03。改动保留在实际加载的 `lzl-dsh-repair`，未提交、未推送。

本轮采用“短期细节随时间更替、长期内容先查目录再读正文”。复用现有存储与账号身份权限，不自动迁移旧档案、不把所有聊天转为永久知识，也不增加额外模型总结或向量服务。

## 为什么值得改

原实现已有短期细节、概要淡化及长期事实，无需重做。实际不足是：短期停用内容仍可被检索；满容量时无法自行腾位；长期查询缺少目录、正文分页及按稳定 ID 读取；近期内容和长期正文的召回规则不完全一致。新增 Token 记账还会改变整个生活文件的版本，使一次记忆搜索之后的读写被计费事件误判为冲突。

这些问题先用虚构数据复现，再分别修复和回归；没有依据“多加一个库可能更好”迁移私人数据。

## 使用效果

- **短期经历**：保留近期用户原话的细节，继续沿用默认 3 天细节期、30 天概要主动召回期。过期后只按现有概要检索和返回；较早概要仍可在明确检索时找回，接近容量上限时才按已有规则淘汰普通淡化旧事。固定事项、未完成约定及有效成长证据受保护。
- **长期记忆**：明确要求长期记住的事实、资料和重要旧事仍走原长期存储。先查标题、来源和短命中片段，选中稳定 ID 后分段读取正文；不用每次把大量旧正文加入模型上下文。真实用户临时称呼、扮演和一次性要求不自动成为长期事实。
- **目录与检索**：支持英文大小写、空白多关键词、中文词法候选、相关度排序和分页。当前属于词法检索，不承诺同义词或完整语义理解。命中当前话题的完整条目优先获得提示词空间。
- **纠正与遗忘**：纠正、停用、删除和撤销使后续索引与派生结果同步变化；已经压缩丢失的细节不会凭空恢复。删除受管记忆不宣称删除了 DSH 聊天历史或外部备份。
- **界面说明**：“记忆”页补充长期目录说明；生活页改为“短期经历与淡化概要”，解释时间更替及固定保留。原有编辑、删除和草稿布局保留。

本轮保持所有现有开关和额度。自动记忆、成长、自主活动及娱乐时间钱包仍关闭；Token 额度开关保持原已开启状态，每日 50,000、每月 200,000、预留 16,384 未改。用户仍需通过既有设置决定是否开启自动记忆或允许模型写入。

## 实现和一致性修复

### 短期召回

管理 `snapshot()` 保留停用记录以支持查看和撤销；模型改用独立 `recall()`，在查询、排序和分页前严格筛选账号、身份及 active 状态。过细节期后先投影为概要，再做匹配，避免通过残留在磁盘的旧细节找到内容。

`dafeiyu_experience_search` 保持原工具名，新增 offset/limit/nextOffset 和稳定 ID 读取。搜索只返回受限片段，按 ID 读取最多返回当前仍允许召回的 12,000 字符；停用内容及其他身份不可读取。附加账号继续只有原两项经历工具，不获得主人长期档案权限。

`recallRevision` 基于本身份的记忆、成长和记忆策略生成，排除 Token、钱包及其他身份；更新在同一 LifeStore 写锁内复核该版本，再从最新 state 原子保存。原全局 revision 继续兼容管理界面与旧调用。Token 单独变化不阻断记忆读写，真实记忆或策略变化仍拒绝旧版本。

接收新记忆的授权事务内，先按原条件清理符合淘汰条件的普通淡忘旧事，再判断 5,000 条上限；不清除 seen 去重证明，全部受保护时原子拒绝而不强行腾位。真实复述强化前处理已经过期的细节，避免刷新时间后将旧原文重新当作清晰记忆；有效成长证据可保留原文，但模型仍只能召回概要。

### 长期目录与正文

新增 `dafeiyu_memory_index` 和 `dafeiyu_memory_read`，复用既有主人/可信桌面权限。目录只返回来源、范围、标题、片段、稳定 ID 和 revision；正文分段读取要求匹配当前版本，使用 nextOffset 连续取段。原 `dafeiyu_memory_search` 保留兼容。

派生词法索引只在进程内存中存在，按源 revision、账号身份和类型缓存，最多 8 份。每次查询先完整验证 MemoryLedger 更正视图，再使用缓存；损坏、更正冲突或删除挂起时拒绝召回，不回退旧索引。索引不形成另一份权威数据，也不写持久文件。

每字段仅前 16K 字符建立 postings，超长条目仍作为完整文本核验候选，保留尾部命中；片段查找按 16K 分块处理，避免为 MiB 正文生成全文位置数组。正文读取处理 UTF-16 字符边界。目录/内容返回深复制，调用方不能污染后续缓存。

### 派生结果和上下文

- 撤销更正后清除依赖错误版本的成长；模型更新回执也遵守清晰度投影，停用后不附带正文。
- 未执行自主候选绑定源内容指纹，派发前及等待资源后的授权检查重新核对源、范围、状态、清晰度和话题。源变化只跳过并延后候选窗口，不自动生成替代执行；未知执行和投递证明不重放。
- 512 字符宿主预算优先保留角色小卡、默认女性、身份关系和完整临时表达政策；可选短期注入让出空间。1024 及以上继续保留短期份额；不足的记忆用工具按需检索。

## 2026-10-26 实际桌面续验

本人解锁后，通过实际 DSH 原生窗口完成以下只读操作：

1. 打开“记忆”，看到长期目录说明及既有 8 条记录；输入既有标题关键词后筛选为 1 条。
2. 打开该条的“查看与纠正”，摘要与正文均已读取，保存纠正和删除仍禁用。未编辑正文，私人内容未纳入验收报告。
3. 输入一个不存在的检索词，读回 0 条及“没有找到记忆，可以换个关键词或状态。”；清空后恢复 8 条，点击“读取最新记忆”后保持。
4. 打开生活页并刷新，读回“短期经历与淡化概要”说明及 0 条记录；自动记忆、成长、自主活动仍关闭。实际滚动查看该区说明与空状态，排版无阻断。
5. 当日开始检查时 QQ 已退出登录，NapCat 为 `waiting_qrcode`。显示原接收小号的当前二维码，本人扫码后再次回读 `phase=ready`、`selfMatches=true` 和 DSH 三项在线标记；QQ 页显示已登录，刷新首页显示“已验证在线”。没有重放旧登录请求、重启容器或发送测试消息。

## 当前范围

这轮改善的是保留、检索和一致性，长期存储仍沿用既有文件大小、条目长度及权限限制；不自动导入 Obsidian、网盘或外部资料。普通旧概要仍是原有的有限摘录，不把它宣传成模型生成的完整知识总结。后续只有真实资料量、检索漏查或性能证据表明需要时，才升级更复杂的存储或语义检索。
