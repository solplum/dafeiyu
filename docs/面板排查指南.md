# 大肥鱼面板排查指南

> 从设置面板的折叠「教程与排查」迁出（2026-10-28 页面减重）。QQ 连接篇在面板内保留了一份；
> 本文档是四篇的完整合集，改动面板时以本文档为准同步更新。

## QQ 连接（面板内保留）

1. 到「高级 · 安装与更新」检测 QQ 接入套件。Linux QQ 和 NapCat 共用一个容器，启动与更新只需操作一次。
2. 到「聊天 · QQ账号」检查小号登录，明确点击获取二维码后，用手机 QQ 扫码确认小号；容器运行不代表已经登录。
3. 二维码反复登录失败时，可到「高级 · 安装与更新」的 QQ 接入套件点击「重启 QQ 服务」，保留配置和登录资料；重启会短暂断开 QQ，完成后再检查登录状态。
4. 到「聊天 · 聊天对象」配置可接待的用户和关系，再核对接收小号、本机 OneBot 地址和令牌，保存生效。用已启用用户私聊小号测试，仍未回复时检查当前页最近收发和模型状态。

参考：[NapCat 接入教程](https://napneko.github.io/guide/napcat)

## 手机连接

1. 电脑和手机连接同一网络。在安卓 11 及以上的开发者选项开启「无线调试」，首次使用需先在系统或 ADB 中完成配对和授权。
2. 核对手机当前 Wi-Fi 地址和连接端口，填写 IP:连接端口后保存生效。配对端口与连接端口不同；换网络或重开无线调试后地址可能变化，旧配置不会靠反复重试自动修正。
3. 同时使用 VPN 或虚拟网卡时，调试页可能显示虚拟地址；应核对电脑可以连接的真实 Wi-Fi 地址，不盲目照抄虚拟网卡地址。地址变化不代表配对失效。
4. 点击「连接配置设备」，只连接该已配对地址，再查看在线状态。USB 设备填写序列号并点击「检测手机连接」；不会扫描或改用其他手机。

参考：[Android 无线调试教程](https://developer.android.com/tools/adb#wireless)

## 语音设置

1. 先确认个人 QQ 已在线，再到「高级 · 声音」选择识别服务和语言；本地服务缺资源时，点击下载 / 准备资源并等待就绪。
2. 接收语音需要开启「允许 QQ 语音转写」，保存生效；发送语音需单独开启并配置语音发送服务，可选本机声音或远程 API。
3. 在依赖列表补齐缺失组件，再明确点击合成检测。合成成功仅说明生成音频成功；收到 QQ 语音和实际识别结果后，才能确认收发链路可用。

## 消息引擎

1. QQ 消息由原生 DSH 会话处理。到「高级 · 模型服务」选择服务。使用 API 服务时填写 URL、协议和 Key；账号登录服务按宿主登录方式配置。保存后可明确点击实际 API 测试，测试可能产生少量用量。
2. 选择宿主默认模型；已有 QQ 会话需点击「重建 QQ 会话」，才会改用新模型。新会话会采用当时的默认模型。
3. 若未收到回复，先检查 QQ 登录与当前页最近收发，再检查模型测试结果；组件缺失或版本问题到「高级 · 安装与更新」检测。
