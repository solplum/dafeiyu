## 声音

「设置 → 大肥鱼 → 设置 → 声音」可以选择默认音色、试听，或允许大肥鱼逐条选择音色。连接参数收在高级设置；在线试听才提示可能费用。本机当前使用 MLX Audio 0.6.1 与固定版本 Qwen3 TTS 0.6B CustomVoice 8bit，默认 Serena，允许 AI 逐条选择；目录包含九个预设。逐条选择不会改默认，语音工具也不能修改收件人或权限。

trial5 的清晰录音在转写前失败，随后只读取原消息 WAV 成功。旧通用 API 的 3 秒时限是代码事实，但当次未捕获明确超时错误，因此不能认定它就是 trial5 的直接原因。现已将 `get_record` 改为单次有界 30 秒等待，并保留取消、WebSocket/HTTP 停止及未知结果不重放；转写前读取或转换失败会更新当前、固定脱敏的 `lastResult`，不再沿用上一条结果。已进入转写后的失败和取消语义保持不变。

较早复验曾出现同音字误识别，例如将“大肥鱼”转成“大飞鱼”；保留真实转写，不把文字后改冒充识别准确。返回转写文字与准确理解指令是两项验收，涉及精确对象时仍需核对。

临时处理文件有界且在处理后清理，核验音频仅保存在私有证据目录。QQ 录音必须先通过账号准入与会话队列，再由 NapCat 转换；不能读 Linux 容器路径或把占位文字当听懂。发送结果未知不重试，同会话合成中的重复调用会拒绝。

## 视频浏览

「设置 → 视频平台」分别展示浏览、独立账号和发布准备。打开页面只读当前状态；检查按钮才发起有界平台读取。B站与抖音采用独立检查编号，重复、失权、运行实例替换与迟到结果都有门禁。

B站固定社区源码并使用独立 Python 环境，只注册七项读工具。公开搜索、视频详情、抽样画面与 BV 号回读已实测；原始插件强制登录读取公开详情的问题由只读 fork 修复。仅缺少凭据文件时使用 SDK 原生匿名 Credential，既有凭据损坏则停止，不绕过平台授权或风控。上游完整 runtime、登录工具、私信监听和自动评论没有启用。

抖音通过本机已安装的 DSH Ego 插件和真实 ToolRuntime 管道读取，固定主机和数字视频链接，最多三帧。公开页面测试曾遇到登录提示、人工验证，也曾没有可确认的搜索内容；均停止或明确未完成，没有声称看完视频。真正的视频采样与理解仍需独立账号到位后验收。网页标题、封面、存在 video 元素不等于读取了实际画面。

普通脚本调用仍受原控制门禁限制。内部固定读取脚本只对当前主人任务或持续有效的 owner 面板 probe 发放一次性调用证明，绑定 Agent、任务、源码参数和调用编号；取消、共享占用及未知清理继续生效。面板检查不会伪造 QQ 入站、主人身份或执行模型回合。
