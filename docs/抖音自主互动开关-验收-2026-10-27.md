# 抖音自主互动开关验收（2026-10-27）

## 当前结果

实际 DSH 已加载本轮10个源码文件及5个测试文件的精确增量，运行就绪、空闲、无待应用配置。没有替换整个运行仓库，也没有覆盖其他并行改动。

「生活与成长 → 自主浏览 → 高级设置」新增“允许自主点赞”“允许自主关注”“允许自主评论”，保存后分别控制 `autonomy.policy.douyinInteractions.like/follow/comment`。三项默认关闭；实际宿主只读回查也均为关闭。旧配置只投影默认值，不因读取或升级重写私人配置。

三种动作的真实控件及业务回执绑定尚未现场核验，宿主各项就绪状态均为 `bindings-required`。保存许可不会让未核验动作直接执行，未核验项不出现在自主模型可用动作枚举中。本轮没有真实点赞、关注或评论，没有调用真实模型，没有平台请求、GUI操作或音频测试。

## 配置和执行保护

- 三项许可独立保存，owner、CAS及持久化校验沿用现有生活设置；不能由模型或网页开启。
- 执行还须同时满足自主活动、浏览、抖音平台、账号身份、免打扰、次数、Token及娱乐时间政策。保存不会立即启动活动。
- 权限取活动开始时与当前许可的交集。活动中开启只作用于后续新活动；关闭已允许项并保存会取消当前抖音自主活动。忙碌时可“仅保存关闭的抖音互动”，不会夹带其他草稿或增权。已发动作不自动撤回。
- 复用专属自主工具与控制占用，不开放通用点击、填表、脚本、终端、QQ、手机或登录工具。后台 Ego SDK 和原有静音媒体保护保留。
- 互动只绑定本次最新作品观察；关注另核验同作品的稳定作者标识。点赞、关注只设置为开启，已有状态不会反转。每活动每项至多一次，评论最多500字，禁止控制字符。
- 评论活动不向模型注入私人话题或聊天摘要。记录只接受受控工具业务证据，不能把模型文字或 HTTP 200 当作发送成功。
- 发起前持久保存账号代际、活动、目标及正文对应关系，再用单次执行证明派发。实际请求与业务回执必须核对账号、对象、正文或目标状态；先确认的回执即使遇到撤权也保留。
- 同账号同目标的同类自主互动跨活动、重新绑定与重载保留防重复；评论不能改正文后重发。结果或持久化不确定时保留未知证明及账号占用，停止后续动作，不重放。旧 owner 草稿审批路径保持独立。
- 读写分别沿用持久限频；等待只发生在尚未发送的动作前，等待后重查权限、账号及风控。本地限频不是平台安全阈值的保证。
