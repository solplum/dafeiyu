## 用户能够设置的内容

新增入口：加载本版本后，在“设置 → 大肥鱼 → 生活与成长”中查看。

- 自动整理日常 QQ 私聊：默认关闭。近期经历保留实际用户原话、时间、账号、身份及来源，不把助手声称做过的事当成操作证据。
- 记忆淡化：普通细节期默认 3 天，普通概要主动召回期默认 30 天，均可调整。再次真实提及可强化；搜索或自动读取本身不会强化。已经压缩的细节不会因再次提及或固定保留而凭空恢复。
- 固定保留和未完成约定：保持可召回，不按普通旧事淡化。普通旧事会压缩细节；容量接近上限时可自然淘汰久远、非固定且无重要成长依据的记录，去重摘要仍保留。
- 纠正、停用、撤销、删除：新经历和旧档案均有对应入口。“停用”仅退出召回；“删除”清除受管源内容、相关更正历史/摘要与派生成长。不会宣称同时清除了 DSH 自身聊天历史或外部备份。
- 成长：默认关闭。当前轻量规则覆盖表达篇幅、直接/温和语气、玩笑偏好及自述兴趣。明确长期反馈可立即生效，普通反馈需跨 3 个日期积累；一次临时要求、引用或扮演不改长期人设。核心角色卡不自动改写。
- 多账号：经历按 QQ 和身份隔离。附加账号只可用 `dafeiyu_experience_search`、`dafeiyu_experience_update` 处理自己的经历；主要使用者的旧档案、终端、手机、发送和其他工具不因此开放。
- 时间钱包：默认关闭且额度为 0，等待用户设置。每日基础额度当天使用，每月零花时间固定到账并永久结余；每月到账和额外发放均去重。20/120 分钟仅是讨论和隔离预览示例。
- 自主活动：默认关闭。分别设置主动聊天、允许平台、接收账号、免打扰时段、每日次数、最小间隔和单次时长。候选时间持久保存并加入随机性，有话题和额度才执行。未回复的主动聊天不继续追发。

## 自主执行与恢复

自主起草和浏览使用 DSH 原生隔离 Agent，不分流给外部代码执行器。起草禁止所有工具；浏览只允许独立空间中的读取、导航和滚动，目标限已选的 B站/抖音域名，禁止登录导入、点击提交、填表、点赞、关注、评论、私信、上传下载、终端和手机。

浏览工具成功观察后的输出可存为“未核实网页摘要”，不能冒充用户自述或直接改变核心人设。加载、暂停、离线及未观察到的休眠时段不计娱乐时间；用户交办任务不走娱乐钱包。各平台共享同一钱包和同时活动限制。

新合法入站消息会请求取消自主活动。实际工作和清理结束前不释放占用，也不叠加执行。原进程中断、结果未知、QQ 送达未知均保留证明，重启不重放。核实旧活动已停止后，可在面板解除挂起，仍不会重新执行旧任务或重发旧消息。

旧档案删除中断时保留仅含删除后数据的受管计划，并阻止召回；主人可从记忆页明确点击“确认完成中断的记忆删除”，继续完成已确认的删除，不恢复旧内容。

## 实际浏览器验收

独立本地页面使用实际 `LifePanel`、React/ReactDOM 与实际存储服务，数据为虚构验收数据，执行器关闭。

已实操并回读：每日基础额度从 20 改为 25 分钟；额外发放 7 分钟后余额为 127 分钟；刷新后保持；纠正经历；确认删除；刷新后被删经历未恢复。浏览器任务空间已经结束。

证据见 `evidence/browser-final.json`、`evidence/browser-acceptance.txt`、`evidence/browser-after-delete.txt` 和 `evidence/life-panel-browser.png`。组件钩子/处理器测试还覆盖了保存失败保留草稿与确认删除按钮。

## 尚未执行的现场验收

- 尚未使用本轮新调度器向真实 QQ 账号主动发送消息，或用真实模型自主浏览 B站/抖音。
- 本轮自主浏览路线为浏览器，没有启用手机自动刷视频。
- 人设成长目前是可解释的有限规则积累，不是模型权重训练或任意内容的自动技能习得。

当前结论是“四轮实现、合并回归、实际宿主加载和面板读取通过”；自主聊天与真实平台浏览仍未做现场验收。

## 复现

```sh
npm test
npm run check
```

单独重现隔离浏览器页面：

```sh
npm ci --prefix tests/preview-runtime --ignore-scripts --no-audit --no-fund
node scripts/life-preview.mjs
```

预览服务仅绑定回环地址，用临时目录保存虚构数据，退出时清理，不读取生产配置。
