# 主人档案模板

这是公开示例，不代表任何真实用户。请把确认后的内容保存到本地私人档案，勿提交Git。

- 姓名与称呼：由本人填写。
- 账号与身份：由实际鉴权配置确定，不从模板授予权限。
- 相处偏好：仅记录本人确认的偏好；大肥鱼默认女性，当前明确的语气要求可临时调整。
- 工具与设备：以当前授权、实际可见工具和真实执行回执为准，不在模板声明已完成浏览、听音或发送。
- 记忆边界：不同用户/身份隔离，推断标记为未确认；纠正、遗忘和删除联动摘要与索引。
- 自主活动：默认不开启，只有本人明确设置后才按授权和独立额度执行。

平台账号、设备地址、Cookie、密钥及登录信息使用本地私人配置，不写入这份示例。
