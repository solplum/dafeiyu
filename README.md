# 大肥鱼 · dafeiyu

基于 DeepSeek Harness 的伴侣项目，包含原生设置面板、按账号隔离的记忆、QQ 接入、手机工具、用户任务与自主活动分账，以及独立平台账号和浏览控制。

此仓库保存经过筛选的项目源码、测试和必要开源依赖。账号配置、登录状态、私人记忆、Token账本、截图与运行日志不在仓库中；克隆仓库不会继承任何现有账号或自动连接实际设备。

## 目录

- `packages/dsh-dafeiyu`：DSH Cordis 插件、原生设置界面及受控工具。
- `packages/companion`：独立伴侣内核和公开角色、配置模板。
- `packages/phone-mcp`：Android MCP 工具。
- `scripts`、`skills/dafeiyu`：检查、安装、预览与维护入口。
- `tests`：离线回归，默认阻止真实平台、模型和设备操作。
- `vendor`、`patches`：带来源、许可证及哈希的第三方资源和补丁。

现有包名 `lzl-dsh`、`dsh-dafeiyu` 等保持兼容，不随 GitHub 仓库名修改。

## 开发检查

需要 Node.js 18 或更新版本。安装依赖不会安装官方 DSH 宿主或为任何平台登录。

```bash
npm install --ignore-scripts
npm test
npm run check
```

部分原生能力依赖实际宿主、macOS 权限、Ego Lite 或已授权设备，离线测试不代表这些能力已经在克隆机器验收。安装与账号操作前先阅读包内 README；不要用空白仓库配置覆盖已有私人配置。

## 当前验收边界

在维护者已授权的实际 DSH 环境，主人接口和新独立自主模型分别完成抖音的打开、读取、单次切换与停止。账号在动作前后匹配，媒体保持静音暂停；切换前的观察与稳定作品编号关联，切换后编号确实变化。停止正式关闭该活动自己的 Space，保留登录 profile 和共享浏览器。

浏览使用 Ego 官方后台 SDK，原生适配精确批准已核验版本及二进制指纹，目前包括 0.6.1.11 和 0.6.1.13。活动按需新建临时 Space，状态未知时保留证明，不补建或重放；GET 不自动探测。主人和模型流程的前台应用采样未观察到 Ego 前置，采样只覆盖当次窗口，不代表所有版本、所有时刻或其他页面的保证。

自主浏览只开放专属只读工具，每次最多三次内容观察；有界业务回执区分模型工具与执行器清理。真实模型用量和娱乐时间分别记账，暂停或计时存储异常不补扣清理等待。克隆、安装或恢复会话不会自动开启自主活动；启用仍须主人配置账号、身份、范围及额度。

原长桌面会话再次超过完整请求保护线后保持暂停，已有恢复入口不会清除未知证明或重放原请求。容量保护继续检查完整请求、工具历史和真实输出预留，输出上限配置与正式恢复分别核验；尚未完成真实长会话压缩维护恢复验收。

当前浏览读取实际页面文字和播放元数据。视频画面/声音理解、持续播放、评论、私信、上传与发布未被这组验收覆盖；B站和X真实接入尚未完成，不自动恢复暂停。完整离线与有限现场边界见 [验证记录](docs/ACCEPTANCE.md)。
