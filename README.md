# 大肥鱼 · dafeiyu

基于 DeepSeek Harness 的伴侣项目，包含原生设置面板、按账号隔离的记忆、QQ 接入、手机工具、用户任务与自主活动分账，以及独立平台账号和浏览控制。

此仓库保存经过筛选的项目源码、测试和必要开源依赖。账号配置、登录状态、私人记忆、Token账本、截图与运行日志不在仓库中；克隆仓库不会继承任何现有账号或自动连接实际设备。

## 目录

- `packages/dsh-dafeiyu`：DSH Cordis 插件、原生设置界面及受控工具。
- `packages/companion`：独立伴侣内核和公开角色、配置模板。
- `packages/phone-mcp`：Android MCP 工具。
- `scripts`、`skills/dafeiyu`：检查、安装、预览与维护入口。
- `tests`：离线回归，默认阻止真实平台、模型和设备操作。
- `vendor`、`patches`：带来源、许可证及哈希的第三方资源和补丁。

现有包名 `lzl-dsh`、`dsh-dafeiyu` 等保持兼容，不随 GitHub 仓库名修改。

## 开发检查

需要 Node.js 18 或更新版本。安装依赖不会安装官方 DSH 宿主或为任何平台登录。

```bash
npm install --ignore-scripts
npm test
npm run check
```

部分原生能力依赖实际宿主、macOS 权限、Ego Lite 或已授权设备，离线测试不代表这些能力已经在克隆机器验收。安装与账号操作前先阅读包内 README；不要用空白仓库配置覆盖已有私人配置。

## 当前验收边界

在维护者的实际 DSH 环境，抖音的打开、读取、单次切换与停止已分别取得原生模型工具证据；使用本人确认的同一账号，静音、暂停并在停止时清理自建视频页。桌面目标会话经过正式容量预览与恢复，后续输出上限为 8,192；原完整请求估算及 75%/90% 保护保留，旧请求不重放。

这不代表所有账号、浏览器版本或旧会话均可直接复用。原生 Ego 适配目前固定受支持版本及二进制指纹；其他旧会话、未知执行与未核对记录保持保护。视频画面/声音理解、持续刷视频、评论、私信、上传与发布未被这组浏览验收覆盖。B站与X的真实接入尚未完成，不自动恢复暂停。

自主活动不会因克隆、安装或恢复会话而开启；用户任务按实际模型用量记录，与自主Token及娱乐时间账本分开。当前离线快照验证见 [验证记录](docs/ACCEPTANCE.md)。
